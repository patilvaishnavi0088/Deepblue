# 🐠 Deepblue – Digital Aquarium

An interactive digital aquarium created using **HTML, CSS, and JavaScript**.

🌐 **Live Demo:** [Open Deepblue Aquarium](https://patilvaishnavi0088.github.io/Deepblue/)

## 🌊 Features

- 🦈 Animated shark moving across the aquarium
- 🐠 Different types of fish
- 🖱️ Single-click interaction to create a fish
- 🐟 Double-click interaction to create a school of fish
- 🪼 Animated jellyfish
- 🐙 Animated octopus
- 🫧 Rising bubbles
- 🌿 Animated seaweed
- 🌊 Underwater gradient background
- ✨ Automatic movement and animations

## 🎮 How to Use

1. Open the Deepblue website.
2. Click anywhere in the aquarium to create a fish.
3. Double-click anywhere to create a school of fish.
4. Watch the shark, jellyfish, octopus, bubbles, and seaweed move automatically.
5. Enjoy the underwater experience!
