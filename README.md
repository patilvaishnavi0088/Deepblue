# 🐠 Deepblue – Digital Aquarium

Deepblue is an interactive digital aquarium created using HTML, CSS, and JavaScript.

It provides an underwater experience with animated sea creatures and interactive fish.

## 🌊 Features

- 🦈 Animated shark moving across the aquarium
- 🐠 Different types of fish
- 🐟 Click anywhere to create a fish
- 🐟🐟 Double-click to create a school of fish
- 🪼 Animated jellyfish
- 🐙 Animated octopus
- 🫧 Rising bubbles
- 🌿 Animated seaweed
- 🌊 Underwater gradient background
- ✨ Automatic movement and animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🎮 How to Use

1. Open the Deepblue website.
2. Click anywhere in the aquarium to create a fish.
3. Double-click to create a school of fish.
4. Watch the shark, jellyfish, octopus, bubbles, and seaweed move automatically.
5. Enjoy the underwater experience!
